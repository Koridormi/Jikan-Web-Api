Curiosidad de JavaScript

A pesar de que null es considerado "falsy", cuando se compara directamente con un 'false' usando el operador estricto '===', el resultado es 'false'. Esto se debe a que el operador '===' compara tanto el valor como el tipo de dato, y null no es igual a 'false' en términos de tipo de dato.
